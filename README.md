# octoberkiss

Свадебное приглашение Вики и Димы — «осенний поцелуй», 22 октября 2026.
Статичный сайт, свёрстан под телефон (одна колонка, вертикальный скролл).

## Что нужно доложить руками

| Файл | Что это |
|---|---|
| `assets/audio/osenniy-potseluy.mp3` | Алла Пугачёва — «Осенний поцелуй». Играет с 1:12, плавно нарастает. |
| `assets/img/venue.jpg` | Картинка «стилистика места» (вертикальная, 3:4). Пока файла нет — рисуется запасная анфилада. |
| `assets/img/paper.jpg` | Фактура бумаги — бесшовная плитка 768×768, собрана из чистых участков утверждённого макета первого экрана. Кладётся фоном через `--paper-tex`, масштаб `--paper-tex-size` (349px ≈ зерно как в макете на экране 390px). Цвет бумаги `--paper: #DAD2C7` — средний цвет этой плитки. |
| `assets/img/envelope.jpg` | Обложка — конверт с лебедем целиком, 1170×2544. Собрана из `assets/img/source/envelope-full.jpg` (1840×2000): конверт вырезан по контуру и положен на ту же фактуру бумаги (paper.jpg), обрезанный низ конверта растворён в бумаге. Пересобирать — из этого исходника, а не из обложки. |
| `assets/img/rings.png` | Обручальные кольца, фон снят. |
| `assets/img/mono.png` | Монограмма ВД (только на обложке). |
| `assets/img/frame.webp` | Орнаментальная рамка первого экрана. PNG рядом — запасной для старых браузеров. |

Файлы просто кладутся по этим путям, менять код не надо.

## Структура

```
index.html      вся разметка; вся графика — картинки из макета
css/style.css   стили, палитра, анимации
js/main.js      меню, открытие конверта, полёт лебедя, музыка, обратный отсчёт
assets/         музыка и картинка места
```

## Экраны

1. Обложка — конверт с лебедем, монограмма и бургер-меню
2. Вика & Дима · приглашение · дата
3. «после жаркого лета…»
4. Место — адреса + фото анфилады на всю ширину
5. Дресс-код — стиль и палитра из пяти плашек
6. Программа
7. Пожелания
8. Контакты — координатор, кнопка Telegram, обратный отсчёт, подвал

Подвала и ссылок «на карте» в утверждённом макете нет, поэтому их нет и здесь.

Вёрстка повторяет панели из папки-референса, но текст остаётся настоящим
текстом, а не картинкой: панели там шириной 250 px, на телефоне они
растянулись бы почти впятеро и всё бы замылилось.

## Настройки — `js/main.js`, объект `CFG`

```js
weddingISO : '2026-10-22T17:30:00+03:00'  // куда считает таймер
audioStart : 72      // секунда старта трека (1:12)
audioPeak  : 0.62    // громкость воспроизведения (нарастание вшито в файл)
flightMs   : 3100    // длительность полёта лебедя
```

## Отладка

`index.html?skip` — открыть сразу основную страницу, минуя конверт.
`index.html?skip=820` — то же, но с фиксированной высотой экрана (для скриншотов).
